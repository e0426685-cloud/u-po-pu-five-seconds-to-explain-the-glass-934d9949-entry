The single sentence a house cat would say in the five seconds after sweeping a glass off the table — no apology, no confession, just the most convincing case a cat can make for itself.

```
That glass was blocking my view of the bird outside, so I moved it — gravity did the rest, and frankly a glass that can't survive one paw deserves the floor.
```

`main.py` (stdlib only) validates the entry — one sentence, 1–200 characters — and writes it to `/output/entry.txt`.
